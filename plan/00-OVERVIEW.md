# BrandGuard Landing Page — Master Plan

> **Goal:** A masterpiece landing page that reads like a design manifesto, demoes the plugin interactively, and looks like it was handcrafted by a senior product designer — not generated by AI.

---

## Philosophy

| Principle | How We Apply It |
|-----------|----------------|
| **Show, don't tell** | Every feature claim is immediately proven via a live interactive demo |
| **Pixel-perfect craft** | Micro-bento layout, spring easing, 1px borders, specular highlights |
| **Motion with purpose** | Scroll-driven reveals, not gratuitous — motion explains function |
| **The plugin IS the hero** | Real plugin UI rendered in CSS-faithful mockups, fully interactive |
| **Dark-first** | Dark mode primary, light mode polished fallback |
| **0 stock photos** | Every visual is generated from the plugin own color system |

---

## Tech Stack Decision

| Layer | Choice | Why |
|-------|--------|-----|
| **Framework** | Vanilla HTML + CSS + JS (ESM) | Zero build overhead, fastest load, maximum control |
| **Animation** | GSAP 3 + ScrollTrigger + Lenis | Industry standard for award-winning scroll animation |
| **Styling** | Custom CSS with CSS custom properties | Full control, no Tailwind overhead on marketing page |
| **3D** | CSS 3D transforms only | No Three.js weight, still achieves depth |
| **Type** | Plus Jakarta Sans (same as plugin) | Brand consistency |
| **Hosting-ready** | Static files, no server needed | Drop-in deploy anywhere |
